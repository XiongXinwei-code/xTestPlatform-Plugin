# 更新记录

## 未发布 - 2026-11-06

- 优化：重新按操作用途划分为 97 个步骤、109 个操作；打开/关闭、启停、使能/禁用、读/写独立，仅七组高度相似操作保留下拉；单功能页移除功能选择框，不兼容原大类入口。

- 新增：`StartAcquisition` 的共享 SDK 线程优先级、高水位、持续积压与重复告警间隔配置；完整保留 109 个操作，全部配置可由页面和平台助手读写。
- 新增：采集/池状态公开请求与实际线程优先级、恢复状态及 RX 队列诊断；停止保留证据，成功重新启动重置。队列满仅为疑似溢出，硬件丢帧数保持未知。
- 新增：输入快照、PDO 样本与运动反馈公开主机读取完成的单调时钟来源、频率及硬件时间不可用标记，不改变原构造和已有 `ReceivedTimestamp`。
- 明确：本地年龄不含读取前的 RX 排队时间；SDO 反馈时间记录在多次读取后，数据不保证原子一致。主动清旧、历史淘汰和软件序号跳过分别解释，不当作硬件丢帧。
- 限制：优先级作用于含采集、SDO 和输出的共享 SDK 线程，不新增 RX/告警线程，也不保证 Windows 硬实时；HPCIe-2E、DC 及 250/500 μs 现场验证仍未完成。

## v1.0.0 - 2026-11-05

- 新增：独立 ZLG EtherCAT 插件及 28 个功能步骤，包含 109 个操作，覆盖主站、PDO、双读取功能池、CoE/SDO、I/O、运动和厂商维护能力。
- 变更：相似操作通过强类型 Operation 下拉框选择，仅显示、校验和执行当前功能；参数切换、刷新及卸载前保存，不兼容旧步骤入口。
- 变更：全部参数保留为平台助手可读写的公开类型字段，描述逐操作列出参数、前置条件和返回值；未选参数保存但不求值。
- 新增：`BeginExit` 开始退出步骤，锁存退出并拒绝新业务写入/运动，保留输入读取和退出操作，不代表运动已停止。
- 新增：周期读取与常驻读取分别使用固定功能池；读取项增减仅更新配置，输入队列由通道唯一工作循环读取。
- 新增：ENI 预期周期与 DC 要求配置，区分 250/500 μs 固件总线周期与 Windows 后台调度。
- 新增：独立运动状态机、SDO/PDO 映射、模式与停止反馈校验，不依赖其他运动插件。
- 新增：独立步骤编辑器、表达式和变量路径校验，以及刷新/卸载前保存。
- 修复：编译产物移除研发说明和离线目录文件，补全插件描述、标准图标和步骤说明表。
- 新增：从站枚举显示 ENI 索引、固定地址、在线/就绪状态与可序列化映像范围，保留离线项；普通从站操作支持可选索引表达式。
- 新增：ENI 字段类型、位宽与位偏移查询/校验；PDO/SDO 写入增加兼容默认 Bytes 的标量类型选择，完整保留 64 位整数精度。
- 新增：PDO 读取可返回带序号的样本；等待新样本支持 long 序号表达式，两个固定读取池的线程模型保持不变。
- 修复：有符号 8 位输出溢出回绕、整数输出静默截断及浮点转换的隐式舍入；类型与长度不符明确报错。
- 修复：纯输入/纯输出映像的零长度调用、连续队列运动所需停止反馈映射不完整、退出期间排队的 OP 请求及板载输出/锁存的共享归属。
- 变更：全部步骤补充中文页面与目标摘要，明确单站/全局范围、返回类型、单位及前置条件；保留发布检查要求的英文工具箱路径。数值编辑支持十六进制，无效输入不能静默沿用旧值。
- 变更：当前交付为软件初版；HPCIe-2E 的 SDK 兼容性、驱动器与现场时序尚未实测。
