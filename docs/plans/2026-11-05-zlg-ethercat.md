# ZLG EtherCAT 独立插件实施与验收

## 范围与基线

- L3：原生 SDK、通道共享状态、后台读取池、运动及板载输出；不连接设备，不部署宿主，不提交既有未提交改动。
- 用户确认：独立 ZLG EtherCAT 包，不依赖 CAN/CiA402 插件；优先使用提供的 SDK。运动控制独立次级目录。
- 周期读取池、后台常驻读取池为独立功能池。按通道固定读取/调度工作循环，添加/修改/停止读取项只改变池配置，禁止为每项建立 Task.Run、线程、Timer 或循环。
- 手册已通过 GitHub connector 实时读取 origin master：`xTestPlatform_StepPlugin_Development_Guide.md` blob SHA `9ca9f70eb10a14cd9a931bcc3fe7fe5995da93d0`，与本地相同。§18.2 DisplayName 下划线分层。
- SDK 来源：用户指定 PCIe_1.6.13/Windows/examples。仅采用有头文件契约的导出；废弃 RM 开关、旧看门狗和旧 GetRange 不纳入新步骤。
- 开始时已有 Shared/Serialization/StrictStepPluginBase.cs、工具脚本、解决方案、LabVIEWCall、docs/plans 等未提交改动，保留原状；必要注册只做增量。

## 架构决策与契约

1. 独立执行/UI/测试工程。执行层不引用其他设备插件；复用项目现有 SDK 与经过检查的共享源文件。C# UTF-8 无 BOM。
2. 每步骤独立 Setting/Plugin/Executor/Editor/View/VM；Description、设置、编辑器、ValidateWithContextAsync 四处同步。共用基础设施不开放任意 SDK 名称调用或 Action 选择器。
3. Native 是可注入同步适配器，保持真实调用的所有权；固定通道工作线程执行 SDK，排队/表达式/原生等待纳入单步骤期限。超时/取消不代表原生退出；未退出时禁止释放或重新占用物理通道。
4. 同一物理通道唯一输入消费者。Pop 成功后复制映像、发布不可变快照；输入队列路径与 FAST/SHADOW 异步路径明确隔离。PDO/I/O/运动写入由唯一输出所有者合并，轴区域禁止通用写绕过。
5. 两个读取池独立命名、配置和状态，复用固定调度设施。后台池按新样本、周期池按单调时钟截止点发布。池项以 ItemName 标识；更新在受控边界生效；停止项等待其在途发布退出。暂停/删除不关闭通道读取任务。
6. 快照携带软件序号、主机接收时间、数据源、积压与质量状态；不把主机接收时间当硬件采样时间。历史记录有界，溢出显式报告。
7. SDK 看门狗、自动清错、就绪丢失超时按实际复位语义处理；禁止后台盲目重发旧目标或喂狗掩盖控制失效。运行ENI和映像长度校验优先。
8. 停止先拒绝新业务命令，保留停轴需要的收发，再确认工作线程真实退出及关闭。关闭不是物理停轴证明；错误保留中文上下文、原码和异常详情。
9. 设备状态/编码器单位/模式由显式配置决定；无硬件不宣称实时性、轴兼容或安全停止通过。板载功能按PCIe-1E16证据限型。

## 能力选择与分工

- 主规划：ECC planner；架构：architect，已按上述数据流与资源归属执行。
- 核心行为：ecc:tdd-workflow，以故障测试/假SDK驱动，不强制泛化覆盖率、checkpoint提交或未经授权hooks（用户AGENTS优先）。
- 主审查：csharp-reviewer；专项 silent-failure-hunter 检查超时/取消/后台传播；security-review 检查原生长度、文件路径、ENI解析、变量目标与DLL加载。
- windows-desktop-e2e 方法用于实际WPF控件运行；宿主/台架不可用时单独记录，不以编译替代。
- 最终 ecc:verification-loop，采用本项目.NET构建与测试。
- Native、静态步骤/UI、运动模块文件独立后可并行；根负责运行时/双池/集成。核心并发与设备动作必须由未编写对应模块的原生子Agent独立只读审查并复审修复。
- 不新增外部契约工具：同一构建内共享C#契约；不安装MCP、不修改模型/审批、不启用自动学习。

## 实际结果（持续更新）

- 远端手册核对：通过，GitHub connector；shell直连GitHub失败已改用现有连接器。
- 软件实施、Release 构建、97 项离线测试、109 个步骤加载及独立审查已完成；现场与宿主集成边界详见验收记录。
- 用户补充目标：HPCIe-2E，通用驱动器，250 μs / 500 μs，要求 DC。软件以 ENI 周期/DC 配置核对、OP/DC 诊断和容量受限队列供帧支持该配置；不以 Windows 工作线程宣称硬实时运动。
- 硬件、实际总线周期、运动、STO、断线/停止：未执行，未连接设备、未执行任何真实 SDK 调用。

## 已实施与最终验收入口

- Core/UI 独立模块、109 个静态步骤及独立编辑页面，18 个独立运动步骤；新增 BeginExit 拒绝退出后的新业务与排队绑定，并保留停止、去使能、解绑与读取。
- 每通道固定 SDK 循环、固定周期读取循环、固定常驻读取循环；命名池和项均为配置。输入队列只有一个消费者；项停止等待实际发布退出。软件采样跳过量与历史淘汰量可查询。
- SDK 调用 Pending/Running/Withdrawn 原子状态、软超时隔离、真实退出后关闭；序列号归一物理占用；板级维护禁止与本进程其他通道共用。
- 运动 PDO 只允许 Queue，逐命令入队回执保留控制字边沿；周期输出前检查独立轴有效期，不能以新的目标掩盖过期事实；队列水位受厂商容量限制。周期输出期间拒绝阻塞型邮箱操作。
- HPCIe-2E 官方能力表的 PDO watchdog 与通用 SDK 导出存在适用范围差异，按型号拒绝看门狗步骤。板载 I/O 仅开放已核实的 PCIe-1E16。证据见模块 Native/README.md。
- 最终完整离线回归 97/97；最后配置失败状态清理定向回归 20/20，独立复审通过。命令、修复及限制统一记录在 [验收记录](../reviews/2026-11-05-zlg-ethercat/acceptance.md)。
- 回退：不部署宿主，不改变现有序列；新目录可独立移除。未修改既有 LabVIEW 实现或还原用户既有改动。
