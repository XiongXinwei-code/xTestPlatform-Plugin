# CiA402 绑定令牌与共享会话生命周期修复

任务等级：L3（运动控制资源、停止语义、取消与跨步骤共享）。保留工作区已有变更，不改父 CAN。

## 证据与根因

- 用户提供 1.0.3 现场详情：会话 40957665 首次终止于 2026-10-22 18:57:06 +08:00，来源为“绑定步骤调用方令牌取消”，传输无隔离、无通信失败，底层已经释放；后续读取的调用方令牌、步骤令牌及 IsAbortRequested 均未取消。
- BindAxisExecutor 将绑定调用方令牌直接传入 AxisSession；AxisSession 长期注册该令牌并在取消时关闭会话。步骤调用令牌不具备整个共享轴运行生命周期的契约。
- 开发手册 §6.1.1 明确 Execution 资源可跨步骤/线程共享，执行结束或引擎停止时兜底回收。轴会话应由资源表和显式解绑持有，而非绑定步骤的短期令牌。
- 现场日志能证明该令牌的取消触发错误释放，不能证明宿主具体为何取消它；不对宿主线程或超时实现作无证据断言。

## 风险与兼容

- 不屏蔽控制步骤取消、不清除 I/O 隔离、不自动重绑或恢复使能。没有增加会话“永久保活”，执行结束仍须由宿主执行资源回收。
- 保留已有显式生命周期令牌构造签名，仅供调用方确实持有整个会话生命周期的场景；插件 BindAxis 不再把自己的步骤令牌传进去。
- 不改变设置结构/步骤标识/对象字典/PDO 编码。回退二进制会恢复旧缺陷；1.0.3 与 1.0.4 设置格式相同。
