# ZLG EtherCAT 步骤合并（L3）

## 范围与用户授权

- 将 109 个独立步骤入口归并为 28 个功能步骤，步骤内用强类型 Operation 下拉框选择唯一动作；保留全部 SDK、PDO、SDO、I/O、双读取池及独立运动控制功能。
- 用户明确不需要旧序列兼容：不保留旧插件注册、旧入口别名或迁移层。原动作设置可作为内部强类型请求投影，不是旧序列入口。
- 用户补充全部功能和参数都要能被平台助手读取、写入和调用。参数必须公开、强类型且可序列化；不能隐藏在 UI、委托或不透明 JSON 中。
- 已核对远端 master 手册，SHA `9ca9f70eb10a14cd9a931bcc3fe7fe5995da93d0`。本轮合并按用户明确要求覆盖 §18.1/§18.3 禁止模式切换条文，其他规范继续遵守。不能宣称与上述两条同时完全一致。
- 不改采集线程、运动状态机、原生协议和设备安全策略；不执行设备动作、不部署运行宿主、不提交。

## 架构与能力选择

- ECC planner：当前 Codex 分阶段规划；architect：分析注册入口、设置与助手、活动请求投影、UI 保存和生命周期前置检查。
- 各组独立 Setting/Plugin/Executor/EditorPlugin/ViewModel/XAML；公开扁平参数、独立 Operation 枚举，内部显式 switch 投影到原动作设置。禁止任意字符串透传运行时操作。
- 活动字段决定业务校验、求值、请求和 UI；全部字段仍须可被助手无损读取和保存。已核实当前宿主会预编译全部表达式，但不求值，且编译失败不阻断预热；插件不声称过滤宿主预编译。
- 同名参数的语义/约束/默认值由生成器检查，输入/输出映像与文件源/目的说明随操作更新。保留明确连接、ENI 从站索引、数据类型等身份信息。
- 生命周期前置检查同时识别组 ID 与选中动作，不能把同组的查询或停止误认创建或启动。
- ECC C# reviewer、silent-failure-hunter：检查操作路由、取消/错误传播、保存失败和切换重入；security-review：检查助手输入类型、非法操作枚举拒绝及设备动作边界；verification-loop + Windows desktop 方法：执行构建、实际 WPF 页面测试、离线测试、宿主纯函数助手契约检查及差异审查。
- 保留已有动作行为测试，新增 28 组覆盖 109 动作、活动参数隔离、未知枚举拒绝、UI 切换、生命周期和助手写入回读测试。独立只读审查由原生子 Agent 承载，因为新入口涉及设备动作路由与共享资源生命周期。
- 不新增独立外部 API 或契约框架：同一构建共享类型原子演进。没有可用硬件，现场实时周期/DC/伺服行为均不计为通过。
