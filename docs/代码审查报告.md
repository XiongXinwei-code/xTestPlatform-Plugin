## 5. 未核实清单（需硬件 / 特定环境，不能从代码判定）

1. **LIN**：NI-XNET 驱动是否自动处理 PID 奇偶位与 0x3C/0x3D 经典校验（插件内无实现，`CalcProtectedId` 为死代码）
2. **NiDaq**：`len/len2` 参数是字节还是元素语义；超时后孤儿阻塞线程与 `TaskStop` 的并发表现
3. **LabVIEWCall**：`lvLib.dll` 的 `len/len2` 语义、`LvFlattenHelper.UseBigEndian=true` 的字节序假设、VI 可重入性、`Resources\LVlib` 是否必需
4. **CAN**：Vector/Kvaser/PEAK/Tosun 真实收发、总线负载与错误帧统计；NiXnet/Peak/Kvaser/Tosun 适配器仅做模式级检查（未逐字段核对厂商头文件）
5. **VISA**：`TMO_VALUE` 是否真正生效、`ReadLine` 对 `\r\n` 的处理、`Write+FlushWrite(true)` 的 EOI/终止符组合、二进制响应实际损坏程度
6. **SerialPort**：软超时后底层阻塞读是否真正放弃（存在吞掉下一次数据的风险）
7. **OpcUa**：需真实服务器；`ns=2;s=x` 命名空间索引解析、消息编码未暴露
8. **Http**：`Connection: close` 与 .NET 默认头合并的优先级；204/304/HEAD、Content-Length 精确读取、chunked 与 EOF 结束均未运行验证
9. **协议时序类**：UDS 0x27 安全访问 key 算法与延迟、Flash 刷写对真实 ECU 的行为、DoIP 0x03 版本协商、SOME/IP SD 实际订阅效果
10. **构建结果**：沙箱阻断，未验证编译通过与 `-p:Platform=x64` 组合告警
