# xTestPlatform 步骤插件列表

> 本文档列出当前解决方案中已开发的所有步骤插件。

## 概览

| 分类 | 插件组 | 步骤数量 |
|------|--------|----------|
| Instrument | VISA | 7 |
| Communication | Modbus | 6 |
| Communication | CAN（含 UDS） | 6 + 8 |
| Communication | OPC UA | 9 |
| Communication | SerialPort | 5 |
| - | LabVIEW Call | 1 |
| DataAcquisition | NI DAQ | 11 |
| **合计** | | **53** |

---

## 1. VISA 插件（仪器通信）

通过 NI-VISA 驱动与 GPIB、USB-TMC、TCP/LAN、串口等仪器通信。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| VISA_Open | `IO.VisaOpen` | 打开 VISA 仪器会话，支持 GPIB、USB-TMC、TCP/LAN(SOCKET/INSTR)、串口等资源 |
| VISA_Close | `IO.VisaClose` | 关闭已打开的 VISA 仪器会话 |
| VISA_Write | `IO.VisaWrite` | 向 VISA 仪器发送命令字符串 |
| VISA_Read | `IO.VisaRead` | 从 VISA 仪器读取响应数据 |
| VISA_Query | `IO.VisaQuery` | 向 VISA 仪器发送命令并读取响应（写+读组合） |
| VISA_WaitOPC | `IO.VisaWaitOpc` | 等待仪器操作完成（*OPC? 查询） |
| VISA_BatchWrite | `IO.VisaBatchWrite` | 批量发送多条 VISA 命令 |

---

## 2. Modbus 插件（工业通信）

支持 Modbus TCP 和 RTU（串口）两种传输方式，进行寄存器/线圈读写。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| Modbus_Connect | `IO.ModbusConnect` | 建立 Modbus 连接，支持 TCP 和 RTU（串口）两种传输方式 |
| Modbus_Disconnect | `IO.ModbusDisconnect` | 断开 Modbus 连接 |
| Modbus_Read | `IO.ModbusRead` | 读取 Modbus 寄存器或线圈 |
| Modbus_Write | `IO.ModbusWrite` | 写入 Modbus 寄存器或线圈 |
| Modbus_BatchRead | `IO.ModbusBatchRead` | 批量读取多个 Modbus 寄存器/线圈 |
| Modbus_BatchWrite | `IO.ModbusBatchWrite` | 批量写入多个 Modbus 寄存器/线圈 |

---

## 3. CAN 插件（汽车总线通信）

支持 CAN 2.0 Classic、CAN FD、CAN XL 协议，兼容 NI、PEAK、Vector、ZLG 硬件适配器。

### 3.1 基础 CAN 操作

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| CAN_Open | `IO.CanOpen` | 打开 CAN 通道并建立连接 |
| CAN_Close | `IO.CanClose` | 关闭 CAN 通道 |
| CAN_Read | `IO.CanRead` | 读取 CAN 报文 |
| CAN_Write | `IO.CanWrite` | 发送 CAN 报文 |
| CAN_Cyclic_SendStart | `IO.CanCyclicSendStart` | 启动周期性 CAN 报文发送 |
| CAN_Cyclic_SendStop | `IO.CanCyclicSendStop` | 停止周期性 CAN 报文发送 |

### 3.2 UDS 诊断协议

基于 CAN 总线的 UDS（统一诊断服务）协议操作，用于 ECU 诊断。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| UDS_DiagSession | `UDS.DiagSession` | 切换 UDS 诊断会话模式（默认/编程/扩展） |
| UDS_SecurityAccess | `UDS.SecurityAccess` | UDS 安全访问（种子-密钥认证） |
| UDS_ReadDataByID | `UDS.ReadDataByID` | 通过 DID 读取 ECU 数据 |
| UDS_WriteDataByID | `UDS.WriteDataByID` | 通过 DID 写入 ECU 数据 |
| UDS_ReadDTC | `UDS.ReadDTC` | 读取 ECU 故障码（DTC） |
| UDS_ClearDTC | `UDS.ClearDTC` | 清除 ECU 故障码（DTC） |
| UDS_RoutineControl | `UDS.RoutineControl` | 执行 ECU 例程控制（启动/停止/查询结果） |
| UDS_RawRequest | `UDS.RawRequest` | 发送自定义 UDS 原始请求报文 |

---

## 4. OPC UA 插件（工业物联网）

支持 OPC UA 客户端连接、读写、订阅和数据采集，兼容匿名和用户名密码认证。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| OpcUa_Connect | `OpcUa.Connect` | 建立 OPC UA 连接，支持匿名和用户名密码认证 |
| OpcUa_Disconnect | `OpcUa.Disconnect` | 断开 OPC UA 连接 |
| OpcUa_Read | `OpcUa.Read` | 读取 OPC UA 节点值 |
| OpcUa_Write | `OpcUa.Write` | 写入 OPC UA 节点值 |
| OpcUa_BatchRead | `OpcUa.BatchRead` | 批量读取多个 OPC UA 节点 |
| OpcUa_BatchWrite | `OpcUa.BatchWrite` | 批量写入多个 OPC UA 节点 |
| OpcUa_Subscribe | `OpcUa.Subscribe` | 订阅 OPC UA 节点变化通知 |
| OpcUa_DataAcq_Start | `OpcUa.DataAcqStart` | 启动 OPC UA 数据采集任务 |
| OpcUa_DataAcq_Stop | `OpcUa.DataAcqStop` | 停止 OPC UA 数据采集任务 |

---

## 5. SerialPort 插件（串口通信）

直接通过系统串口进行数据收发，适用于简单串口设备通信。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| SerialPort_Open | `IO.SerialPortOpen` | 打开指定串口并配置通信参数（波特率、数据位、停止位、校验位） |
| SerialPort_Close | `IO.SerialPortClose` | 关闭串口连接 |
| SerialPort_Read | `IO.SerialPortRead` | 从串口读取数据 |
| SerialPort_Write | `IO.SerialPortWrite` | 向串口写入数据 |
| SerialPort_Query | `IO.SerialPortQuery` | 向串口发送数据并读取响应（写+读组合） |

---

## 6. LabVIEW Call 插件

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| LabVIEW Call | `LabVIEWCall` | 调用 LabVIEW 虚拟仪器（VI）文件，执行其中定义的功能。适用于需要在测试流程中集成 LabVIEW 功能的场景 |

## 7. NI DAQ 插件（数据采集）

通过 NI DAQ 硬件进行模拟/数字信号采集与输出，支持多通道同步采集。采用 Config → Start → Read → Stop 工作流模式。

| 步骤名称 | StepTypeId | 功能说明 |
|----------|------------|----------|
| NiDaq_DI_Read | `NiDaq.DiRead` | 读取 NI DAQ 数字输入通道的状态值 |
| NiDaq_DO_Write | `NiDaq.DoWrite` | 写入 NI DAQ 数字输出通道的状态值 |
| NiDaq_AI_Config | `NiDaq.AiConfig` | 配置 AI 采集任务（通道、采样率、时钟源、触发等） |
| NiDaq_Encoder_Config | `NiDaq.EncoderConfig` | 配置编码器计数任务（Counter 通道、解码类型、PPR 等） |
| NiDaq_Sync_Config | `NiDaq.SyncConfig` | 配置 AI + 编码器同步采集任务 |
| NiDaq_Task_Start | `NiDaq.TaskStart` | 启动已配置的 DAQmx 任务（通用） |
| NiDaq_AI_Read | `NiDaq.AiRead` | 从已启动的 AI 任务读取采样数据 |
| NiDaq_Sync_Read | `NiDaq.SyncRead` | 从已启动的同步任务读取 AI + 编码器数据 |
| NiDaq_Encoder_Read | `NiDaq.EncoderRead` | 读取编码器计数值 |
| NiDaq_Task_Stop | `NiDaq.TaskStop` | 停止并释放 DAQmx 任务（通用） |
| NiDaq_Data_Analyze | `NiDaq.DataAnalyze` | 对采集的数据进行分析处理（如频域分析、统计等） |

---

## 技术说明

- **运行环境**：.NET 8
- **序列化方式**：MessagePack 3.x
- **插件架构**：每个插件组包含执行层（`*.StepPlugin.dll`）和 UI 层（`*.StepPlugin.UI.dll`）两个独立项目
- **表达式支持**：标注 `[ExpressionField]` 的字段支持运行时表达式求值
