# CAN 步骤结果专项约定

依据用户 2026-10-30 的明确要求，CAN 包（基础 CAN、DBC、CANopen、UDS/Flash、XCP）所有步骤正常成功统一返回 `TestStatus.Passed`，用于显示 PASS。此项覆盖开发手册 3.4.0 §2.4 中正常返回 `Completed` 的规定；其余开发范式继续严格遵循手册。

- 只修改正常成功出口。错误、内部超时仍为带中文详情的 `Error`，用户主动取消仍为 `Aborted`。
- PASS 表示当前步骤约定的操作成功，不扩大为设备合格、报文上总线、后台永久健康或电机停稳的证明。
- 不改变共享生命周期、原生调用退出、取消和旧代次隔离逻辑；不将失败状态统一映射为 PASS。
- 其他插件继续遵守原手册状态规范。源码检查的例外只限 `CAN/CanPlugin/`。
