# 更新记录

## v1.0.31

- VI Server port 可在步骤中设置，默认 3363，覆盖端子加载、编辑和实际执行；按端口验证进程身份与引用归属，切换端口不会复用另一端口的引用。
- 目标开发环境不再限定 2026 或 x64；仍需先安装并打开能够运行目标 VI 的 LabVIEW。独立 x64 桥自身的 Runtime 依赖不变，当前只调用 .vi。
- 调试日志明确区分已配置端子数量、实际写入平台变量数量和整个调用流程耗时；调用标识及端口放入详情，成功状态保持 Completed。
- 编辑页面优化右侧状态与预览布局，区分尚未在线检查和检查失败，避免文字裁切及连接状态误导。

## v1.0.30

- 第一阶段限定为已运行的 LabVIEW 64 位开发环境调用 .vi；删除旧 Compatibility 步骤注册，只保留 Adapter.LabVIEWCall。
- 以本机 LabVIEW 2026 无硬件示例复现并修复面板图像释放返回值误判、端子 JSON 中文乱码、真实数组元数据与连续调用不兼容的问题。
- 刷新端子在托管侧按完整路径与类型保留输入值和输出映射，配置不再依赖原生桥回填。未知字段和不匹配的端子结构仍明确报错。
- 核对 VI Server 监听进程的 PID、启动时间、路径、版本与 x64 架构，在提交前和响应后验证实例及取消状态，避免向错误实例发送或发布旧结果。
- 增加官方纯计算 VI 的显式启用集成测试和 WPF 编辑器联调；常规回归不自动调用 LabVIEW 或设备。

## v1.0.29

- 加载与运行 VI 的原生桥移入独立 x64 辅助进程，处理宿主混载第三方旧 C++ 运行库时，选择 VI 导致整个平台退出的问题。辅助进程核查系统运行库来源与版本。
- 本机 VI Server 未监听时，加载前给出 TCP/IP 与端口设置提示。明确目标 LabVIEW 需保持运行。
- 桥异常记录阶段、PID、退出码及有界诊断。取消后追踪已提交操作，禁止迟到结果发布和旧请求补发；关闭辅助进程入口不会等待未返回的原生调用。
- 补充真实子进程故障注入、协议边界、取消/退出和端口探测测试。真实用户 VI 加载仍需在配套环境中复测。

## v1.0.28

- 对照 LabVIEW 2026 x64 SDK 修正 VI 引用为无符号 32 位，图像句柄仍为原生指针；支持扁平布尔的所有非零真值。
- 向实际 VI 查询输入和输出方向，拒绝遗漏输入、错误方向、字段变化和非空闲状态。未映射的顶层标准错误簇也会检查；警告在步骤日志中保留编号和来源。
- 执行、编辑和离线校验的文件探测脱离调用线程，取消或超时后不会继续提交旧操作。补充了 TCP、运行时版本和最小访问权限的安装说明。

## v1.0.27

- 端子类型、配置树和真实类型描述逐项检查，保留数值宽度，支持一维数组。无效值返回可定位的错误。
- 修正 x64 桥读取容量单位、截断判别和有界分配。取消或超时后，拒绝与尚未退出的原生调用重叠。
- 离线编辑与校验，切换和卸载时保存原步骤的修改。手动读取面板受期限和编辑器请求代次限制。
- 接入仓库编译、打包及回归测试。新步骤 ID 为 Adapter.LabVIEWCall，原标识继续使用同一执行器和编辑器。

## 未发布
- 迁移：共享错误入口接入 SDK 1.2.8 工厂，超时与 VI 加载/运行/参数读写保留原异常链；保留原包装接口，用户取消返回 Aborted。最终错误由配套宿主统一记录，需先升级宿主。

## v1.1.0 - 2026-08-18
- 新增：`LabVIEWCall` 增加 `TimeoutMs` 参数（默认 0 表示不限制），可在编辑器中配置
- 修复：VI 调用为阻塞式非托管调用、无法响应取消，VI 不返回时会永久阻塞序列；现配置 `TimeoutMs` 后超时终止等待并返回 `Error`
- 新增：编辑器对 `TimeoutMs` 增加校验（`LV_TIMEOUT_INVALID` 负数报错、`LV_TIMEOUT_UNLIMITED` 填 0 时警告可能永久阻塞）
